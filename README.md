# C++ Driver Payroll System

A console-based C++ application developed as part of my first-year Software Engineering coursework at the University of Lancashire.

## Project Overview

This application processes fictional logistics driver payroll data, calculates payments based on miles driven, and manages payroll information across multiple months.

## Features

- Reads driver information from text files.
- Calculates monthly payments based on mileage and pay rates.
- Processes payroll data for January, February and March 2026.
- Uses case-insensitive driver ID searching.
- Calculates tax based on annual income rules.
- Displays payroll information in the console.
- Writes payroll results to output files.

## Technologies Used

- C++
- Microsoft Visual Studio
- File handling
- Vectors and structures
- Functions, loops and conditional statements

## Sample Data

All driver information is fictional and included for demonstration and testing purposes.

## How to Run the Project

1. Download the repository as a ZIP file from GitHub.
2. Extract the ZIP file.
3. Open `Payroll System.sln` in Microsoft Visual Studio.
4. In Solution Explorer, right-click the **Payroll System** project and select **Properties**.
5. Navigate to **Configuration Properties → Debugging**.
6. Set **Working Directory** to `$(SolutionDir)`.
7. Click **Apply**, then **OK**.
8. Run the application using **Local Windows Debugger**.

**Note:** The application uses `drivers.txt` and monthly payroll text files. These are included in the repository and must remain in the main solution directory.
